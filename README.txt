CSC HUB website - free hosting steps (no coding needed)

OPTION A - Netlify Drop (easiest)
1. Open app.netlify.com/drop on a computer and sign up free.
2. Drag this whole folder (index.html + notices.json) onto the page.
3. You get a free link like random-name.netlify.app.
4. In Site configuration, change the site name to something like cschub-bakala.

OPTION B - Cloudflare Pages
1. Sign up free at dash.cloudflare.com, open Workers & Pages, create a Pages project, choose "Upload assets".
2. Name it cschub and upload this folder. Your link will be cschub.pages.dev (if the name is free).

Menus change over time, so wording may look slightly different.

To change notices later: edit notices.json (keep the same format) and upload the folder again.
To change phone, address or prices: open index.html in a text editor and edit the lines under "EDIT HERE".
